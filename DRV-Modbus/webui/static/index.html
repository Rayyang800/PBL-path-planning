    工件與任務設定

    分析與深度

    畫面上:橘線 = 影像找到的縫、 洋紅線 = 深度找到的縫(勾選「疊圖」)。深度用 848×480、0.1 mm 單位、8 幀中位數。
    脊線筆跡分析
    不動手臂;重新分析最新一次
    只找縫
    不動手臂;顯示縫合線擷取結果
    近距離深度量測
    home 量 3 組 → 垂直下降 150 mm 再量 3 組 → 回 home,比較精度
    深度設定比較
    唯讀;用設定的板厚當真值,比較 5 組深度設定
    多視角立體重建
    手臂帶相機在物體上方與周圍逐點拍深度 → 合併成點雲、量尺寸 (任何形狀),結果在左邊「立體模型」視窗看。不下筆;筆尖一直比物體高 (設定在下方「多視角立體重建」)

    其他校正

    快速校正
    工件上 ±step,旋轉+平移
    畫圓驗證
    相機找十字 → 繞它畫圓 → 量圓心誤差。先 dry-run 看編號
    筆尖 3D 位置:分身算法 (建議,不動手臂)
    用手眼 (scan3d) + 護貝紙筆尖校正 + home 照片推出筆尖在手臂末端的位置,取代傾斜碰點。底面描繪會自動算,這裡只是查看數值,平常不用按
    筆尖 3D 校正:傾斜碰點 (舊方法,不用做)
    垂直點一個點 → 手臂傾斜 4 次,每次人工把筆尖對準那個點按 c → 算出筆尖相對手臂末端的位置。換筆或重夾後要重做

    立體模型

    左鍵拖曳 旋轉 · 右鍵 / Shift+拖曳 平移 · 滾輪 縮放 · 雙擊 重設
    綠框 = 頂面 (最高的平台)、橘框 = 底面外框;格線 10 mm;紅/綠/藍短線 = 紙面 x / y (往下) / 高度。
